The ten Guardians of the Directions. Eight in the cardinal directions, and one up and one down.

| Direction | Sanskrit                  |
| --------- | ------------------------- |
| North     | Uttara, Udīcī             |
| South     | Dakṣiṇa, Avācī            |
| East      | Pūrva, Prācī, Prāk, Aruna |
| West      | Paścima, Pratīcī, Aparā   |
| Northeast | Īśāna                     |
| Southeast | Agni                      |
| Northwest | Vāyu                      |
| Southwest | Nirṛta                    |
| Zenith    | Ūrdhva                    |
| Nadir     | AdhaH                     |
